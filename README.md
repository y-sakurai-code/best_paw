# Best Paw(ベストパウ)
## サイト概要
### コンセプト
「広告ではなく、同じ犬種・年齢・体質の犬を飼う『飼い主の生の声』を知りたい」というニーズに応えるためのレビューサイトです。犬種特有の悩み（噛む力、アレルギー、体格差）に基づいた詳細な情報を一元管理します。

### テーマを選んだ理由
私自身、犬を飼育しているのですが、ドッグフードやおもちゃ、ケア用品を選ぶ際に、広告情報だけでは自分の愛犬（犬種や年齢、体質）に本当に合うのか判断が難しいという課題を感じていました。  
特に犬は種類によって体格や噛む力、アレルギーの出やすさが大きく異なるため、実際に同じ犬種を飼っている他の飼い主の「生の声」を知るニーズは非常に高いと考えています。  
このアプリは、飼い主目線の詳細なレビューを一元管理し、ユーザーが自分の愛犬に最適なアイテムを効率的に見つけ、愛犬の健康と生活の質の向上に貢献するために制作しました。

### ターゲットユーザ
* 初めて犬を飼い始めたばかりで、どのようなドッグフードや用品を選べば良いか迷っている人
* 現在使用しているグッズに不満があり、愛犬の好みに合う新しい商品を検討している飼い主
* 特定の犬種や年齢層に特化した商品の、メリット・デメリットを詳しく知りたい人

### 主な利用シーン
* ドッグフードを切り替える前に、他の飼い主の「食いつき」や「体調の変化」を確認したい時
* 壊れにくいおもちゃや、しつけ用のおやつを探している際に、実際の使用感を確認したい時
* 特定の犬種特有の悩み（毛並み、関節ケアなど）に対する、おすすめのサプリメントやケア用品を比較したい時

## 実装機能一覧

### ユーザー管理
- **新規登録・ログイン・ログアウト**（Devise）
- **ゲストログイン機能**（ワンクリックで閲覧用アカウントへログイン）
- **プロフィールの編集・退会機能**（論理削除：Discardによる誤ったデータ削除した場合に対応）

### 愛犬管理
- **愛犬登録・編集・削除機能**（複数頭の登録に対応）
- **「思い出箱」アーカイブ機能**（大切な愛犬のデータを保存し、通常リストと分けて管理）

### レビュー・コミュニケーション
- **レビュー投稿・編集・削除**（愛犬の商品に対するレビュー）
- **いいね機能**（レビュー、およびコメントに対するお気に入り登録）
- **コメント機能**（レビューに対する意見交換）
- **通知機能**（自分の投稿へのいいね・コメントをリアルタイムに通知）

### API連携機能（今日のわんこ）
- **Dog API連携によるスライドショー表示**　（外部APIからランダムに5枚の犬画像を取得しログイン後トップ画面にスライドショー形式で表示）

### 検索・管理者機能
- **キーワード検索・タグ検索機能**
- **管理者用ダッシュボード**（不適切投稿の監視・削除、ユーザー管理）

## こだわったポイント

### ゲストユーザーに対する権限設計とUX
採用担当者様がスムーズにアプリを体験できるようゲストログインを実装しました。
一方で、DBの整合性を保つため、コントローラーレベルで「投稿・編集・退会」を制限しました。
また、UI上でもゲスト時には入力フォームを非表示にするなど、セキュリティとUXを両立させました。

### 「思い出箱」アーカイブ機能
愛犬との別れは飼い主にとって大きな出来事です。
単にデータを削除するのではなく、「思い出箱」という形で記録を残し続けられるように設計し、飼い主の心情に寄り添うサービスとしての独自性を持たせました。

### 外部APIを活用した動的なコンテンツ生成
「今日のわんこ」機能では、**外部のDog APIと連携**し、24時間で1回更新の犬の画像を取得する仕組みを構築しました。
単に静的な画像を表示するだけでなく、APIからのレスポンスを処理してフロントエンドのスライドショーへ反映させる一連のデータフローを実装。
これにより常に新鮮なビジュアルを提供できる設計にしました。

### 管理者による健全なコミュニティ運営
不適切なコンテンツが投稿されるリスクを考慮し、管理者専用のadminを構築。
一括管理できるダッシュボードを実装することで、プラットフォームとしての信頼性を確保しました。

## 素材・データについて

### AI生成画像の利用
本アプリ内のメインビジュアルや愛犬のサンプル画像には、**AI（[Gemini]）**によって生成された画像を使用しています。
- 著作権および利用規約を遵守し、独自に生成した素材のみを採用しています。
- 開発段階において、迅速かつセーフティなビジュアル構築を目的として活用しました。

### サンプルデータについて
本アプリに登録されているレビュー内容やユーザー情報は、すべて**テスト用の架空データ**です。
- 実在の人物、団体、および商品とは一切関係ありません。
- 著作権を侵害する恐れのある実在のレビュー転載などは一切行っておりません。
